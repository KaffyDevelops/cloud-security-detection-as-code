# MITRE ATT&CK Mapping

MITRE ATT&CK tags explain the adversary behaviour a detection is intended to observe. They do not prove attribution.

Mappings should use the most specific defensible technique when possible, avoid adding techniques merely for coverage, and be updated whenever the detection objective changes.
